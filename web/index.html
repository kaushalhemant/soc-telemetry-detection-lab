About This System

          

            The SOC Telemetry & Detection Lab is an engineering-grade detection engineering and security operations workspace. It models real-time host and network telemetry, compiles SIGMA YAML detection rules, detects MITRE ATT&CK techniques, and provides incident triage, authentic binary Wireshark PCAP generation, and Burp Suite HTTP proxy history parsing.
          


          
3 Operating Workflows

          

            

              Workflow 1: Run Detection Test

              Execute the 13-scenario deterministic validation suite or fire individual simulated attack vectors to evaluate engine precision, recall, and detection latency against ground truth.
            

            

              Workflow 2: Investigate Alerts

              Search, filter, and triage detected incidents by severity, status, or telemetry source (simulated vs live vs replayed). Open alert details to review raw log evidence and add notes.
            

            

              Workflow 3: Explore Rules & Integrations

              Review SIGMA rule definitions, hot-reload rules from disk, inspect connected endpoint agents, or paste Burp Suite XML proxy logs.
            

          

        


        
        

          
11 Pre-Packaged Threat Vector Simulators

          

            

              SSH Brute Force (T1110.001)

              Simulates high-rate failed authentication attempts against sshd.
            

            

              Webshell Execution (T1059.004)

              Detects web server processes executing unauthorized interactive shells.
            

            

              Privilege Escalation (T1548.001)

              Detects unauthorized SUID binary execution and root shell elevation.
            

            

              Process Hollowing (T1055.012)

              Detects memory unmapping and code injection into suspended processes.
            

            

              BYOVD Kernel Tampering (T1068)

              Detects vulnerable signed kernel drivers loaded to disable security sensors.
            

            

              LSASS Memory Dump (T1003.001)

              Detects credential extraction targeting lsass.exe via comsvcs.dll.

Connecting Real Endpoints (Production Mode)

          

            To stream real telemetry from a remote Linux or Windows server into this SOC engine:
          

          
python agent/collector.py --server http://127.0.0.1:8000

          

            Note: Live unauthenticated endpoint telemetry is categorized as LIVE and does not distort benchmark detection metrics (precision/recall) without ground-truth labels.
