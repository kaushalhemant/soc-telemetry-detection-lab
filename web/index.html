RULE-008 CRITICAL
Process Hollowing & Code Injection
MITRE ATT&CK: T1055.012 | Target: svchost.exe / explorer.exe

Injects shellcode into a suspended target process or unmaps executable pages (NtUnmapViewOfSection) to hide malicious code inside legitimate system processes.

RULE-009 CRITICAL
BYOVD Kernel Driver Tampering
MITRE ATT&CK: T1068 | Target: RTCore64.sys / gdrv.sys

Threat actors load signed but vulnerable kernel drivers to gain ring 0 access and terminate EDR/AV security sensors kernel callbacks.

RULE-010 HIGH
Active Directory Kerberoasting
MITRE ATT&CK: T1558.003 | Protocol: Kerberos TGS (0x17 RC4)

Requests Ticket Granting Service (TGS) tickets for Service Principal Names (SPNs) encrypted with weak RC4-HMAC algorithms to crack service account passwords offline.

RULE-011 CRITICAL
LSASS Credential Memory Dumping
MITRE ATT&CK: T1003.001 | Target: lsass.exe via comsvcs.dll

Abuses legitimate Windows DLLs (comsvcs.dll) or diagnostic utilities (procdump) to dump LSASS process memory to disk for plaintext credential extraction.

What is this project?

          

            The SOC Telemetry Generation & Detection Lab Engine is a full-stack security operations center (SOC) simulation environment. It generates real-time Linux & Windows telemetry, parses SIGMA YAML rules, detects threat vectors (MITRE ATT&CK), and provides incident triage, Wireshark PCAP generation, and Burp Suite HTTP proxy integration.
          


          
How to test features in 3 steps:

          

            
Step 1: Execute Threat Vectors
Click any toolbar button like SSH Brute Force, Privilege Escalation, LSASS Dump, or Kernel Driver Tampering.

            
Step 2: Watch Real-Time Telemetry Stream & Detections
View live authlog/syslog events streaming into the center console while newly triggered detection alert cards populate the left pane with severity colors.

            
Step 3: Open Alert Triage Modal
Click any alert card in the left pane to view MITRE ATT&CK technique IDs, raw log evidence, Splunk/Elastic query conversions, and export binary .pcap network captures!
